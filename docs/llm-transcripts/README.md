# GenAI use log and transcripts

**Course policy (syllabus):** GenAI use must be acknowledged and cited, including the specific
version of the tool. The submission must include the **exact prompt** and the AI's **full response**
in an Appendix. Students are responsible for checking accuracy. Deviations count as academic-integrity
violations.

## How to log
1. Save each chat as its own file here: `YYYY-MM-DD_<tool>_<topic>.md` with the prompt(s) and full
   response(s) verbatim, plus the share link if the tool provides one.
2. Add a row to [LOG.md](LOG.md).
3. Note in LOG.md how you validated the output before using it.

The report appendix (`report/05_appendix.md`) is assembled from this folder.
